# Sicherungskarten – Kurzanleitung für Lehrkräfte

Mit einer Sicherungskarte wird der Lernwelt-Pass eines Kindes **automatisch** gesichert:
XP, Level, Truhen, Figur, Sterne, das Dorf und die Expedition. Geht ein iPad verloren oder wird
es zurückgesetzt, scannt das Kind seine Karte und alles ist wieder da.

- Keine Accounts, keine E-Mail, keine Namen auf dem Server.
- Der Server speichert nur verschlüsselte Stände. Lesen kann sie nur, wer die Karte hat.
- Wer welche Karte hat, steht **nur auf deiner Liste**.

## 1. Karten erzeugen (Admin)

1. `admin.html` → oben **🗂 Sicherungskarten**
2. Gruppenname eingeben (z. B. „5a“ oder „5b Gruppe Rot“), Anzahl wählen → **Karten erzeugen**
3. In der Druckansicht **Karten** drucken, dann auf **Liste** umschalten und die Liste drucken.
   Oder beides als PDF sichern.

> Die Codes sind **nur in diesem Moment** sichtbar. Nicht gedruckte Karten kannst du später
> in der Übersicht löschen und neu nachlegen.

Die Liste sicher aufbewahren (nicht aushängen): Wer eine Karte hat, kann den zugehörigen Pass öffnen.

## 2. Einführungsstunde (ca. 10 Minuten)

1. Alle öffnen die Lernwelt über das **Lernwelt-Symbol** auf dem Home-Bildschirm, nicht über Safari.
2. Karten austeilen. Jedes Kind schreibt seinen Namen darauf. Du trägst die Namen parallel in die Liste ein.
3. Oben auf **📷 QR scannen** tippen und die eigene Karte scannen.
4. Die Frage „Pass mit Karte verbinden?“ mit **Verbinden** bestätigen → „✅ Gesichert“.
5. Kontrolle im Admin: Die Gruppe zeigt „25 von 25 Karten verbunden“.

Kinder ohne Pass scannen die Karte genauso und richten danach ihren Pass ein.

**Kamera geht nicht?** Im Pass → **Sicherung** → „Code von der Karte eintippen“.
Groß-/Kleinschreibung ist egal, 0 und O zählen gleich. Vertippt sich ein Kind, merkt die App das sofort.

**Zu Hause auf einem anderen iPad:** Lernwelt-Symbol öffnen → 📷 QR scannen → Karte scannen → „Pass laden“.
Danach lassen sich beide iPads abwechselnd benutzen, nur nicht gleichzeitig.

## 3. Im Alltag

- Das iPad sichert nach jeder Runde automatisch, sobald es Internet hat.
- Im Pass → **Sicherung** steht „✅ Automatisch gesichert · heute, 10:42 Uhr“.
- Waren zwei iPads mit derselben Karte gleichzeitig offline, gewinnt beim nächsten Abgleich der Stand mit mehr XP.
- Kinder können ihre Karte selbst nachdrucken: Pass → Sicherung → **🖨 Meine Karte drucken**.

## 4. Übersicht und Probleme (Admin → Sicherungskarten)

| Situation | Was tun |
|---|---|
| Karte verloren | Kind druckt sie im Pass nach, oder du liest den Code von deiner Liste vor |
| Neues Kind in der Klasse | Bei der Gruppe **+ Karten nachlegen** (Nummern laufen weiter) |
| Karte an ein anderes Kind geben | Alte Karte **löschen**, neue **nachlegen** – Karten nie weitergeben |
| „Deine Sicherungskarte gilt nicht mehr“ | Karte oder Gruppe wurde gelöscht → neue Karte ausgeben und scannen |
| Karte zeigt lange keine Sicherung (gelb) | Seit über 30 Tagen nicht gesichert: iPad lange nicht benutzt oder ohne Internet |
| Schuljahr vorbei, Gruppe nicht mehr nötig | **Gruppe löschen** (löscht alle gesicherten Stände dieser Karten) |

Nach **2 Jahren** ohne Sicherung werden Stände automatisch gelöscht.

## Datenschutz in einem Satz

Auf dem Server liegen nur verschlüsselte Daten ohne Namen oder Klasse, die nur mit der gedruckten
Karte lesbar sind; die Zuordnung zu den Kindern gibt es nur auf Papier bei der Lehrkraft.
