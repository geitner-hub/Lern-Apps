🧭 Lernwelt-Pass · Sicherungskarten

Drucke deine Sicherungskarte aus oder speichere sie als PDF. Mit dem QR-Code kannst du deinen Pass jederzeit auf einem anderen Gerät wiederherstellen.

Die Karte speichert den Stand von heute. Späterer Fortschritt ist darauf nicht enthalten – am besten kurz vor dem Gerätewechsel drucken.
👩‍🏫 Sammelbogen für Lehrkräfte (mehrere Codes)

Die Kinder tippen in ihrem Pass auf „🔗 Code kopieren“ und schicken dir den Code (z. B. über den Schul-Messenger). Füge hier beliebig viele Codes ein – einen pro Zeile oder einfach hintereinander. Es werden 8 Karten pro A4-Seite gedruckt. Die Codes bleiben auf diesem Gerät, nichts wird hochgeladen.
